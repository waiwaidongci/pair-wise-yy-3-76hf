# 定向取样与剩余长度核销台

由岩芯切片实验室改造而来，按三层拆分承载：

- `server.js` — **请求入口**：HTTP 路由、页面、幂等键解析（`requestId` 或报文指纹）
- `rules.js` — **判定规则**：方案校验、切片核销、更正失效、剩余长度与统计
- `store.js` — **记录存储**：加载/原子落盘、串行事务、幂等记录（`data/directional-sampling.json`，旧 `core-slices.json` 自动迁移留档）

## 规则

- 每根岩芯同时仅一份有效方案，登记顶深、底深、方位角、倾角、取样长度。
- 方案**整单拒绝且不写入**：区间越界（顶底深颠倒、超出岩芯区间、取样长度超过区间）、方位缺失、倾角不在 0–10°、与同孔同箱有效方案区间重叠（端点相接不算）。
- 切片须引用有效方案与相对位置；**超出剩余长度或方向反转只转待复测**，不核销剩余长度。
- 方案更正后关联切片与交付**立即失效**，按新位置重算剩余长度；旧版留档但不计统计。
- 重复或并发提交**沿用首次结果**（HTTP 头 `X-Replayed: true`）；列表、剩余长度与重载（重启）后状态一致。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 岩芯列表、有效方案、剩余长度、留档、统计 |
| POST | `/api/cores` | 登记岩芯（钻孔、箱号、岩芯区间、负责人） |
| POST | `/api/cores/:id/plans` | 提交方案（已有有效方案则 409） |
| POST | `/api/cores/:id/plan/correct` | 更正方案（旧版及关联切片/交付失效留档） |
| POST | `/api/plans/:id/slices` | 登记切片（相对位置、长度、方向） |
| POST | `/api/plans/:id/deliver` | 交付当前方案的有效切片 |

写操作均可带 `requestId` 做幂等；缺省时按「方法+路径+报文」指纹去重。

## 运行

```bash
npm start        # http://localhost:3025
npm test         # 冒烟测试（独立临时数据文件，覆盖全部规则与并发/重载一致性）
```
