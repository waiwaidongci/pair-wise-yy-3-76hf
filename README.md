# 定向取样与剩余长度核销台

由原「岩芯切片实验室」改造，分三层承载：

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 请求入口 | `server.js`、`src/page.js` | HTTP 路由、页面表单、幂等复用 |
| 判定规则 | `src/rules.js` | 方案/切片全部业务判定，纯领域逻辑 |
| 记录存储 | `src/store.js` | JSON 文件原子落盘、写操作串行队列 |

## 运行

```bash
npm start
```

访问 `http://localhost:3025`。数据落在 `data/core-desk.json`（首次启动自动播种）。

## 规则

**方案登记**（顶深、底深、方位角、倾角、取样长度，按孔/箱/岩芯登记）：

- 每根岩芯同时仅一份有效方案；
- 区间越界（顶深<0、底深≤顶深、取样长度超出区间长度）、方位缺失（或不在 0–360°）、倾角不在 0–10°、与同孔同箱有效方案区间重叠——**整单拒绝，不写入**。

**切片**：必须引用方案与相对位置（沿取样方位的米数）。相对位置为负判方向反转，切片长度超出剩余长度判超长，两种情况**只转「待复测」**且不核销长度。

**方案更正**：旧版留档（不计统计），关联切片与交付立即失效并按新位置重算。

**一致性**：重复或并发提交（相同 `Idempotency-Key` 或相同请求体）沿用首次结果；写请求在存储层串行执行，列表、剩余长度、重载后状态一致。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/plans` | 有效方案列表 + 统计 |
| GET | `/api/plans/:id` | 方案详情（切片、交付、历史版本） |
| POST | `/api/plans` | 登记方案 |
| POST | `/api/plans/:id/correct` | 更正方案（旧版留档） |
| POST | `/api/slices` | 登记切片 `{planId,id,offset,length}` |
| POST | `/api/slices/:id/deliver` | 核销交付 |
